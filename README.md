# Craft Lab · 로지텍 크래프트 키보드 연습실

Logitech Craft 키보드의 기능을 직접 따라 하며 익히는 인터랙티브 연습 사이트입니다. (한국어 · English · Español)

👉 사이트: https://yalli2.github.io/logi_craft/

## 구성
- **개요** – 크라운, Easy-Switch, 스마트 F키, 듀얼 OS 키, 백라이트, 표시등, 전원·USB-C, 연결 방식
- **크라운 연습실** – 터치·탭·돌리기, 래칫/프릭션 모드, 누른 채 돌리기, 앱별(Photoshop·Lightroom·Illustrator·Premiere Pro·InDesign·Word·Excel·PowerPoint·Spotify) 미리보기
- **키보드 시뮬레이터** – 스마트 F키, Fn+Esc / Fn+O / Fn+P / Fn+B, Easy-Switch 페어링·전환, 근접 센서 백라이트, 배터리·충전
- **Options+ 설정 연습** – 크라운 Press / Turn / Press & Turn, F키 사용자 지정
- **실전 연습** – 실제 키보드 키 테스트, 단축키 드릴, 타자 연습
- **미션 21개 · 퀴즈 · 문제 해결**
